PRIVACY

Your setup stays yours.

This website

The guide asks about uses, budget, equipment and tool preferences. It does not ask for your name, email, password or API key, and does not request a camera or microphone.

Application code includes no advertising or analytics. Managed hosting receives normal connection information and may add security checks. The page policy blocks inline scripts; a blocked hosting script can produce a browser console warning.

Your choices stay in the page until you download a plan. To continue on a computer, transfer that file yourself and import it into the local wizard. The computer setup link contains no answers. Do not add secrets to a plan.

The desktop application

Jarvis runs on a computer. The phone guide does not install an Android or iPhone app. Optional hand and presence features process camera frames locally; offline command recognition uses a local model. Device access and desktop actions require local permission.

Optional services

Provider links open websites with their own terms and privacy policies. The guide does not provision accounts, make purchases or connect Jarvis to a paid AI or voice provider.

Before sharing

Review plan files and screenshots before sharing them. Never upload private camera images, documents, traffic captures or credentials to a public issue.
