Your setup stays yours.

This website

The setup page asks one question at a time about your purpose, budget, AI account, typing or voice preferences, replies and optional future automation. It does not ask for your name, email, password or API key, does not call any AI provider, and does not request a camera or microphone.

Application code includes no advertising or analytics. Managed hosting receives normal connection information and may add security checks. The page policy blocks inline scripts; a blocked hosting script can produce a browser console warning.

Your setup answers stay in the page. If you copy the link for your computer, the answers are part of that link. If you save them as a file, the file holds your setup answers only. Neither contains anything secret.

The desktop application

Jarvis runs on a Windows computer. A phone can plan and practice, but it does not install an Android or iPhone app and cannot control a computer. Optional hand and presence features process camera frames locally. Camera, mouse control and Windows lock each stay off until you switch them on.

API keys and AI chat

If you choose a cloud AI provider, you paste its key only into the setup page that Jarvis opens on your own computer. The key is kept on that computer and is not shown again. A connection test or chat message is sent only after you tick the box allowing it, and it goes to the provider you chose under that provider's own terms and privacy policy. The monthly budget becomes a local allowance kept on that computer: Jarvis counts its own paid attempts there and stops when the allowance is used. It is not an invoice cap and it is not shared with this website, so also set a hard spend limit with your provider.

Optional services and feedback

Provider links open websites with their own terms. This project does not create accounts or make purchases for you. Feedback is filed as a public GitHub issue, so never include keys, private camera images, documents or other personal details in it.
